# Mustache Enthusiast

**Mustache Enthusiast** es una plantilla web sobre bigotes,
desarrollado con *HTML, CSS, y Javascript*.

## Achivos y uso
- `index.html` : pagina principal.
- `about.html` : pagina de infromatica

para utilizarlo:
1. Descarga o clona el proyecto.
2. Abre la pagina principal en el navegador

Para clonarla:
```bash
git clone https://github.com/mouaadh-dot/bigotes.git
```
